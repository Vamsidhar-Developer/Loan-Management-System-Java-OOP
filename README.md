# Bank Loan Application

A Java-based Bank Loan Application developed using Object-Oriented Programming (OOP) concepts.

## Technologies Used

* Java
* Eclipse IDE
* Git & GitHub

## OOP Concepts Used

* Interface
* Abstraction
* Inheritance
* Hierarchical Inheritance
* Method Overriding
* Polymorphism

## Loan Types

The application supports different types of loans:

* Personal Loan
* Home Loan
* Gold Loan
* Educational Loan
* Vehicle Loan

## Features

* Customer age validation
* Salary eligibility validation
* CIBIL score validation
* Mobile number validation
* Aadhaar number validation
* PAN card validation
* Loan document verification
* CIBIL-based loan interest rate calculation
* Loan approval/rejection based on eligibility

## Project Structure

```text
Loan
   |
   └── LoanImpl
         |
         ├── PersonalLoan
         ├── HomeLoan
         ├── GoldLoan
         ├── EducationalLoan
         └── VehicleLoan
```

## Purpose

This project was developed to understand and demonstrate Java OOP concepts using a real-world Bank Loan Application example.
